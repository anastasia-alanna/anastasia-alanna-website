# Anastasia Alanna Website

Static, responsive website prepared for GitHub Pages and the custom domain AnastasiaAlanna.com.

## Fast edits

Open `assets/js/site-content.js` to update contact details, the Cal.com link, the form endpoint, logo path, and all photo paths.

## Replace photos

Replace the files in `assets/images` while keeping the same file names, or update the image paths in `assets/js/site-content.js`. Every temporary photo is also marked visually with a small replacement note. Remove the `.photo-note` elements after the final images are installed.

## Contact form

Set `formAction` in `assets/js/site-content.js` to the endpoint supplied by Formspree, Web3Forms, or another static-site form provider.

## Scheduling

Set `schedulingUrl` in `assets/js/site-content.js` to the final Cal.com link.

## GitHub Pages

1. Create a new repository.
2. Upload all files from this folder to the repository root.
3. In repository Settings, open Pages and deploy from the main branch root.
4. Confirm the custom domain is `AnastasiaAlanna.com`.
5. Configure the domain DNS records using GitHub Pages documentation.

## Fonts

The site uses Playfair Display, Montserrat as the web-friendly Futura Light alternative, and Great Vibes.
